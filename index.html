Level 01 · Mission Engineering

任务层：无人作战任务

一切设计从所要完成的任务出发

本小组的"系统"服务的顶层任务是无人作战任务——在有人平台难以进入或代价过高的高危场景中，由轮腿式无人作战平台代替或协同有人力量执行作战行动。

M-01

前沿侦察监视

深入交火区前沿，长时间隐蔽侦察，持续回传态势情报。

M-02

协同突击打击

与有人作战单元协同，对既定目标实施多向突击。

M-03

目标精确打击

锁定高价值目标，引导或直接实施精确火力打击。

M-04

排爆除险

雷场探排、未爆弹处置、危险品搬运与销毁。

M-05

战场支援保障

伤员搜救转运、弹药物资前送、通信中继支援。

STAKEHOLDERS

任务相关方

一线指挥员 · 平台操作/监控员 · 情报分析员 · 后勤保障人员 · 友邻作战单元 · 非作战人员 · 敌方对抗力量（约束条件）。

MOE / MOS

任务度量

侦察覆盖率 · 目标识别准确率 · 任务完成时间 · 平台生存率 · 人员零伤亡替代率。

Level 02 · System of Systems Engineering

体系层：智能作战体系

多平台组网 · 有人无人协同的作战架构

无人作战任务由一个多平台组网、有人无人协同的智能作战体系承接——各成员系统大多能独立运行、独立管理，成员间以信息交互为主，整个体系涌现出新的作战能力，并随任务演化持续建设。

SoS-01

指挥控制中心（有人）

任务规划、权限监督、有人无人协同调度，保留"人在回路"决策权。

SoS-02

轮腿式无人作战平台 × N

本组所选"系统"，地面末端智能节点，可多台组网（含空中/水上异构平台）。

SoS-03

通信中继网络

卫星通信、空中中继无人机、地面自组网，保障体系级信息链路。

SoS-04

后勤保障与补给系统

能源补给、备件更换、回收维修，支撑体系持续运转。

SoS-05

情报侦察卫星体系

体系级态势输入源，为任务规划提供全局情报。

成员系统独立运行成员间仅信息交互体系涌现新能力体系永不停止演化
03
Level 03 · Vehicle Engineering

整机层：轮腿式无人作战平台

轮-腿复合构型 · 高速机动 + 复杂地形越障 · 体系末端智能节点

整机采用轮-腿复合构型：平整路面以轮行高速机动，遇台阶、废墟、壕沟等复杂地形切换到腿行越障，兼顾机动效率与地形通过性。它是体系中的末端智能节点，也是"具身智能"的物理载体——通过实体与环境交互实现自主作战能力。

FORM / 01

轮行模式

四轮（或多轮）驱动，平整道路与开阔地高速机动，能耗低、续航长。

FORM / 02

腿行模式

轮腿切换为足式支撑，跨越台阶、碎石、壕沟、楼梯，进入室内与废墟。

FORM / 03

轮腿协同

轮腿同时参与支撑与驱动，实现爬坡、侧移、原地转向等复合机动。

ROLE

整机定位

体系里的末端智能执行节点：接收体系任务 → 自主/协同执行 → 回传态势。

ARCH

整机搭载八大系统

感知 · 决策 · 运动控制 · 任务载荷 · 通信 · 能源动力 · 综合防护 · 健康监测（见下层分解）。

04
Level 04 · Systems Engineering

系统层：整机搭载的八大系统

感知—决策—行动—协同—生存 的完整闭环

整机向下分解为八大系统，构成"感知—决策—行动—协同—生存"的完整闭环：

SYS-01

多模态态势感知系统

光电、红外、雷达等多模态传感器，负责环境与目标探测，输出统一态势。

SYS-02

边缘智能决策系统

搭载具身大模型，在战术端自主规划行为，支持人在回路的监督与接管。

SYS-03

机动与运动控制系统

适配全地形行走与行驶，完成姿态稳定、步态/轨迹执行。

SYS-04

模块化任务载荷系统

可换装侦察、火力、排爆等任务模块，一平台多任务能力。

SYS-05

抗毁保密协同通信系统

抗干扰、加密、自组网，与体系内其他成员交换任务信息。

SYS-06

能源与动力管理系统

动力电池/发动机管理、能源调度与分配，决定续航与机动上限。

SYS-07

平台综合防护系统

装甲防护、低可探测、烟幕干扰等主动/被动防护手段。

SYS-08

健康监测与运维保障系统

各分系统状态自检、故障诊断与预测，支撑体系后勤决策。

Level 05 · Sub-systems

子系统层：各系统的进一步分解

沿感知 - 规划 - 控制主线并扩展保障支线

沿感知 - 规划 - 控制主线并扩展保障支线，各系统继续拆分为子系统：

所属系统子系统功能要点
态势感知系统同步定位与地图构建（SLAM）视觉/激光 SLAM，在无 GPS 环境下自定位并构建环境地图。
多传感器融合光电/红外/雷达时空对齐与目标级融合，输出统一目标列表。
目标识别与跟踪目标检测、分类、威胁排序与持续跟踪。
智能决策系统全局路径规划基于任务与地图的全局机动路线生成。
局部动态避障实时避障与重规划，应对动态障碍与突发威胁。
战术任务决策具身大模型驱动的行为决策：侦察/突击/撤离等战术动作编排。
运动控制系统轮-腿协调运动控制轮行/腿行模式切换决策，轮、腿驱动力的分工与协调。
关节伺服控制腿部关节力矩/位置伺服，步态生成与平衡稳定控制。
轮毂驱动控制轮毂电机转矩分配、差速转向与打滑抑制。
载荷精准执行载荷指向稳定与操作精度控制（瞄准、抓取、排爆操作）。
通信系统通信组网 / 抗干扰 / 数据加密自组网、跳频抗干扰、端到端加密，保障链路抗毁。
能源系统电池管理（BMS）/ 能源调度荷电状态估计、充放电保护、任务级能耗优化分配。
健康监测系统传感器自检 / 故障预测分系统健康评估、剩余寿命预测、降级运行建议。
防护系统主动防护 / 对抗干扰威胁告警、烟幕/软杀伤对抗措施的触发控制。
任务载荷系统侦察 / 火力 / 排爆载荷控制各任务模块的操控、状态管理与快换接口控制。

串联阐述：任务牵引体系，体系定义整机

自上而下的需求分解 × 自下而上的能力支撑

六层之间不是简单罗列，而是自上而下的需求分解与自下而上的能力支撑的双向映射：

[ 01 ]

任务牵引体系

无人作战任务（侦察/突击/排爆）定义了需要什么样的作战能力 → 由此构架多平台组网、有人无人协同的智能作战体系。

[ 02 ]

体系定义整机

体系架构中识别出"地面末端智能节点"这一关键缺口 → 定义整机：轮腿式无人作战平台（轮-腿复合构型，兼顾高速机动与复杂地形越障）。

[ 03 ]

整机分解系统

为实现"感知—决策—行动—协同—生存"闭环，整机向下分解为感知、决策、运动控制、任务载荷、通信、能源、防护、健康监测八大系统。

[ 04 ]

系统细分子系统

沿感知、规划、控制主线细分：SLAM / 多传感器融合 / 目标识别跟踪，全局规划 / 动态避障 / 战术决策，底盘控制 / 关节伺服 / 载荷执行，外加通信、能源、健康监测等保障子系统。

[ 05 ]

子系统落地为模块

每个子系统最终由具体硬件/软件模块实现；模块经部件验证 → 系统集成 → 整机集成 → 体系组网，逐级向上汇聚能力，最终支撑任务完成。

[ ↺ VERIFY LOOP ]

自下而上的能力支撑（验证闭环）

模块能力支撑子系统 → 子系统支撑系统 → 系统构成整机 → 整机组网成体系 → 体系完成任务；任一层级不达标都会沿链路上溯影响任务度量（MOE/MOS）。
